## Security boundary

The production project may contain private databases, environment configuration, API integrations, user data, deployment settings, or other material that should not be public. This showcase intentionally contains safe documentation and public-facing project context only.

No production credentials, `.env` files, database dumps, private certificates, captured traffic, tokens, service-role keys, or private datasets belong here. Future public code additions must use mock data and `.env.example` configuration.
