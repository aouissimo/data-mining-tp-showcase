Code Structure

How the Code Is Organized

Each file maps to a clear part of the workflow.

Main files

  • `src/App.tsx`: controls dataset selection, preprocessing actions, training, and log state.
  • `src/utils/sample-data.ts`: stores the Weather and Titanic sample datasets.
  • `src/utils/preprocessing.ts`: cleaning, normalization, and discretization functions.
  • `src/utils/id3-core.ts`: entropy, information gain, recursive tree building, and prediction.
  • `src/components/TreeVisualizer.tsx`: turns the learned tree into a visual graph.

Runtime flow

  • 1. Load Weather or Titanic data.
  • 2. Apply preprocessing functions.
  • 3. Call `buildID3Tree()`.
  • 4. Display the result in the visualizer.
The code structure mirrors the KDD pipeline step by step.
Raw Data

Understanding the Datasets

The project uses one clean baseline dataset and one more realistic sample dataset.

Weather (Play Tennis)

  • 14 records with categorical attributes.
  • Useful for validating entropy and information gain.
  • Target label: `Play`.

Titanic Passenger Sample

  • 13 sample records with numeric values and one missing age value.
  • Shows why preprocessing is needed before mining.
  • Target label: `Survived`.
Weather gives a clean baseline, while Titanic demonstrates preprocessing and transformation challenges.
Preprocessing

Cleaning and Transformation

The app prepares the data before ID3 training.

Data cleaning

  • `handleMissingValues()` detects null, undefined, and empty values.
  • Mode imputation fills missing values with the most frequent value.
  • The application logs each preprocessing step for explanation.

Data transformation

  • `minMaxNormalize()` scales numeric columns when needed.
  • `discretizeEqualWidth(data, 'Age', 3)` converts age values into bins.
  • After transformation, the data is compatible with ID3 splitting.
ID3 Logic

ID3 Logic in Code

The algorithm measures uncertainty, compares attributes, and builds the tree recursively.

Main functions

  • `calculateEntropy()` measures class impurity.
  • `calculateInfoGain()` compares candidate attributes.
  • `buildID3Tree()` repeats the split until a leaf node is reached.
